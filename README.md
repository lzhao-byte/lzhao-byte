### Hi, I'm Liuhui Zhao 👋

Data analytics lead in Portland, OR, with 10+ years of experience with SQL/Python pipelines, data modeling, and analytics products.
Today I work mostly in **Snowflake**: layered raw → QA → production pipelines, stored procedures / tasks / UDFs, semantic views, and self-service Streamlit apps.
Earlier I built Hadoop/Spark and geospatial ETL pipelines for transportation research. PhD, M.S. Analytics (Georgia Tech). SnowPro Core · AWS Certified Data Engineer – Associate.

Most of my professional work lives in private company repos. The repos below are personal and teaching projects.

**Featured**

- **[Intro to Predictive Analytics](https://github.com/lzhao-byte/used_car_price_predictions)**: a multi-page Streamlit app I built to teach the predictive-analytics lifecycle in company-wide data-literacy training. It walks through data exploration, cleaning, feature engineering, model training (linear models, Random Forest, XGBoost), and a simulation of model monitoring and data drift. Built with Polars, scikit-learn, Plotly, and an optional Snowflake backend. [Live demo](https://intro-to-predictive-analytics.streamlit.app)
- **[Denver Housing Analytics](https://github.com/lzhao-byte/denver-housing)**: about 200K property sales joined spatially with neighborhood features (crime, crashes, tree cover, distance to amenities), plus price models (Lasso, Random Forest, XGBoost) and a Plotly Dash web app. Georgia Tech team project.
- **[Research Topic Modeling](https://github.com/lzhao-byte/topic_modeling)**: scraped 2010–2020 transportation journal papers, then applied LDA topic modeling (Gensim) and co-author network analysis (NetworkX).
- **[workcal](https://github.com/lzhao-byte/workcal)**: company holiday policies as TOML config, turned into workday counts, `WORKDAY()`-style date math, and a `dim_date` table. It ships as a Python library, a CLI, and a Streamlit app, with 98 tests: regression tests against v1 and cross-checks against official US/UK calendars over 41 years. CI runs on GitHub Actions.
